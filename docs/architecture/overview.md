# 系统架构总览

## 五层架构

```
┌─────────────────────────────────────────────────────────────────────┐
│  API 网关层 (Gateway)                Axum HTTP Server               │
│  认证 → 限流 → 路由 → 协议检测                                      │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  协议转换层 (Protocol)              OpenAI / Anthropic            │
│  请求转换 → 内部统一模型 → 响应转换 → 流式事件转换                   │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  路由引擎层 (Router)               Tower Middleware Pipeline        │
│  任务分类 → 熔断检查 → 健康评分 → 模型筛选 → 评分排序 → 最终选择     │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  提供商适配层 (Provider)            HTTP Client + Adapters          │
│  OpenAI / Anthropic / Google / Azure / 自定义...                    │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│  数据存储层 (Storage)              moka + dashmap + DuckDB + JSON  │
│  缓存 (内存) → 状态 (内存) → 日志 (DuckDB) → 配置 (JSON)           │
└─────────────────────────────────────────────────────────────────────┘
```

## 数据流

```
用户请求
  │
  ├─→ 网关层: 认证 API Key、速率限制检查
  │
  ├─→ 协议层: 检测请求格式 (URL 路径)
  │    ├─ /v1/chat/completions → OpenAI 解析器
  │    ├─ /v1/messages         → Anthropic 解析器
  │    └─ /v1/responses        → OpenAI Responses 解析器
  │    └─ 统一转换为 Canonical Model
  │
  ├─→ 路由引擎:
  │    ├─ 任务分类器: 分析请求内容 → 识别任务类型
  │    ├─ 熔断检查器: 查询各模型健康度
  │    ├─ 健康评分器: 综合评分
  │    ├─ 模型筛选: 过滤不可用模型
  │    └─ 评分排序: 选择最优模型
  │
  ├─→ 提供商适配:
  │    ├─ 将统一请求转换为提供商格式
  │    ├─ 调用提供商 API
  │    └─ 将响应转换为统一格式
  │
  ├─→ 存储层: 异步写入调用日志
  │
  └─→ 响应返回 (同步或流式 SSE)
```

## 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 编程语言 | Rust | 零 GC、内存安全、高性能、单二进制部署 |
| Web 框架 | Axum + Tower | 可组合中间件、生态成熟、异步原生 |
| 配置管理 | JSON 文件 | 人类可读、支持 Git 版本管理、热重载 |
| 运行时状态 | moka + dashmap | 进程内存、零依赖、亚微秒级访问 |
| 日志分析 | DuckDB | 嵌入式列式数据库、ACID、单文件备份 |
