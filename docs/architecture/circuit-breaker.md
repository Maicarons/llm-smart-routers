# 智能熔断系统

## 五维智能熔断

```
维度 1: 实时故障统计
维度 2: 延迟趋势预测
维度 3: 健康度评分 (渐进式)
维度 4: 主动健康探测
维度 5: 提供商级联熔断
```

## 健康度评分

```
Health = W_err × (1 - error_rate)
       + W_lat × latency_score
       + W_recent × recent_trend_score
       + W_slo × slo_compliance_score
```

## 渐进式降级

| 健康度 | 状态 | 流量控制 |
|--------|------|---------|
| 0.8 - 1.0 | 正常 | 全流量 |
| 0.6 - 0.8 | 预警 | 降低 20% 流量 |
| 0.3 - 0.6 | 降级 | 降低 50% 流量 |
| 0.1 - 0.3 | 限制 | 降低 80% 流量 |
| < 0.1 | 熔断 | 完全切换到备用 |
